Un flujo simple

Documenta procedimientos web sin tener que construir cada manual desde cero.

1. IniciaAutoriza la captura en la pestaña que quieres documentar.
2. RealizaHaz el procedimiento normalmente. PasoListo registra los pasos.
3. RevisaEdita títulos y explicaciones, reordena pasos y corrige capturas.
4. ExportaGenera un documento Word editable o una versión HTML imprimible.

Funciones

Captura paso a paso

Registra la vista visible tras las acciones realizadas en la pestaña autorizada.

Indicador de clic

Marca visualmente dónde se realizó el clic para que el procedimiento sea más fácil de seguir.

Edición antes de compartir

Permite corregir títulos, explicaciones, orden y contenido de cada paso.

Tapado permanente

Incluye una herramienta para cubrir información sensible dentro de la imagen exportada.

Word y HTML

Exporta la guía para poder editarla, imprimirla o convertirla posteriormente a PDF.

Español e inglés

La interfaz y los documentos pueden generarse en ambos idiomas.
