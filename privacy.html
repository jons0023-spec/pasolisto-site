Política de privacidad

PasoListo es una extensión de navegador que permite crear guías paso a paso a partir de procedimientos que el usuario decide documentar en páginas web.

Datos tratados durante una captura

PasoListo solo inicia una sesión de captura cuando el usuario lo solicita expresamente y selecciona la pestaña que desea documentar.

Durante esa sesión, PasoListo puede capturar la parte visible de la página, detectar los clics realizados, obtener la etiqueta visible del control pulsado y registrar la posición aproximada del clic para generar los pasos del manual.

PasoListo no registra el texto que el usuario escribe en campos de texto.

Almacenamiento local

Los borradores de manuales, sus textos, capturas, indicadores visuales, preferencias y copias de seguridad se almacenan localmente en el perfil del navegador del usuario.

PasoListo no utiliza actualmente servidores propios para almacenar o sincronizar los manuales ni sus capturas.

Capturas y contenido de páginas web

Las capturas pueden contener información visible en la página que el propio usuario haya elegido documentar.

El usuario es responsable de revisar el contenido antes de exportarlo o compartirlo. PasoListo incorpora herramientas que permiten tapar permanentemente zonas de una captura cuando sea necesario ocultar información.

Exportaciones y copias de seguridad

Cuando el usuario exporta un manual a Word, HTML u otro formato disponible, o guarda una copia de seguridad, el archivo resultante queda bajo su control.

PasoListo no controla cómo se almacena o comparte posteriormente ese archivo fuera de la extensión.

PasoListo Pro y claves de licencia

PasoListo dispone de funciones opcionales asociadas a una licencia Pro.

Las compras y la gestión de las licencias se realizan mediante Lemon Squeezy, un proveedor externo de comercio digital y licencias.

Para activar, validar o desactivar una licencia Pro, PasoListo puede transmitir a la API de Lemon Squeezy la clave de licencia y un identificador de la instalación necesarios para gestionar la activación.

Las capturas, los textos y el contenido de los manuales no se envían a Lemon Squeezy durante este proceso.

PasoListo no almacena ni procesa directamente los datos completos de tarjetas de pago.

Uso de los datos

Los datos tratados por PasoListo se utilizan únicamente para proporcionar las funciones solicitadas por el usuario, entre ellas:

  • capturar los pasos de un procedimiento;
  • crear y editar manuales;
  • mostrar indicadores visuales de las acciones;
  • guardar y recuperar manuales localmente;
  • exportar documentos;
  • gestionar la activación de PasoListo Pro.

Venta de datos y publicidad

PasoListo no vende datos de los usuarios.

PasoListo no utiliza la información capturada para publicidad, elaboración de perfiles comerciales, evaluación crediticia ni finalidades ajenas a las funciones de la extensión.

Servicios de terceros

La comunicación externa utilizada para la gestión de licencias Pro se realiza con Lemon Squeezy.

El uso que dicho proveedor haga de la información que recibe está sujeto también a sus propias condiciones y políticas de privacidad.

Cambios en esta política

Esta política puede actualizarse si cambian las funciones de PasoListo, el sistema de licencias o los proveedores utilizados.

Las modificaciones relevantes se reflejarán en esta misma página.
