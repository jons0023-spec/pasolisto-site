Política de privacidad

PasoListo es una extensión para crear guías paso a paso a partir de procedimientos realizados en páginas web.

Procesamiento local

PasoListo guarda los borradores de manuales, sus textos y las capturas asociadas en el perfil local del navegador del usuario. PasoListo no utiliza actualmente un servicio propio en la nube para almacenar esos manuales.

Capturas

El usuario decide cuándo inicia una captura y en qué pestaña. Las capturas pueden contener información visible en la página documentada. Antes de compartir un manual, el usuario debe revisar su contenido y utilizar las herramientas de tapado cuando sea necesario.

Exportaciones y copias

Cuando el usuario exporta un documento o guarda una copia de seguridad, el archivo queda bajo su control y puede almacenarse o compartirse fuera de PasoListo.

Pagos y licencias

La versión comercial utiliza un proveedor externo para procesar las compras y validar las licencias. PasoListo no almacena datos completos de tarjetas de pago.

Cambios

Esta política puede actualizarse para reflejar cambios en las funciones, el sistema de licencias o los proveedores utilizados.
